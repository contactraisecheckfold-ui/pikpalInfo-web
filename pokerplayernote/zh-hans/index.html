如何添加玩家笔记？

打开“玩家”并点击 +。输入玩家姓名与笔记，再点击“添加玩家”。您也可以选择颜色、将玩家标记为收藏，或设置手牌范围。

如何记录牌局？

打开“牌局”并点击 +。输入买入、追加买入、兑现金额、时间与地点等详细信息。使用“全部”、“月”或“年”筛选，查看记录与摘要。

如何备份或导出数据？

打开“功能 → 备份与恢复”。选择“导出备份”，将 JSON 文件保存至“文件”；或选择“导出 CSV”，导出玩家、牌局、地点、牌桌或座位，以供电子表格使用。

恢复备份会发生什么？

在“功能 → 备份与恢复”中选择“恢复备份”，再选择 JSON 备份。确认前请先查看内容。恢复会替换所有当前数据，且无法撤销。若要保留当前记录，请先导出备份。CSV 文件无法用于恢复数据。

应用会在不同设备间同步笔记吗？

记录保存在您的设备上，不会自动云同步。导出 JSON 备份，可保留独立副本或在其他设备恢复。恢复会替换目标设备当前的数据。
