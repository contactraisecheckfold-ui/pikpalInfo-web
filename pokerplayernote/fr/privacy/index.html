Politique de confidentialité de pokerNote

Mis à jour le 28 septembre 2026. pokerNote est développé par Michael Yang (raisecheckfold.com).

Vos données de poker

Les notes sur les joueurs, les éventails de mains, les tables, les sièges, les lieux et les sessions sont stockés dans la base de données locale de l’application. Aucun compte n’est requis. Ce stockage local est distinct des données publicitaires décrites ci-dessous.

Sauvegardes et exports

Lorsque vous exportez une sauvegarde JSON ou un fichier CSV, vous choisissez où l’enregistrer. Les dossiers cloud, les copies partagées et les sauvegardes de l’appareil sont gérés par les services utilisés. Gérez ces copies séparément. Restaurer une sauvegarde remplace les données actuelles de l’application.

Publicité et suivi

L’application intègre des publicités Google AdMob. La publicité peut impliquer la collecte de données et le suivi. Vous pouvez gérer l’autorisation de suivi de l’application dans les réglages de votre appareil.

Politique de confidentialité de Google

Déclarations de confidentialité de l’App Store

La déclaration de l’App Store mentionne la localisation, les coordonnées, le contenu utilisateur, les identifiants, les données d’utilisation et les diagnostics. Certaines catégories peuvent être liées à vous ou utilisées pour le suivi, la publicité, le marketing ou l’analyse. Ces déclarations sont fournies par le développeur et ne sont pas vérifiées indépendamment par Apple. Consultez la fiche pour les catégories et finalités détaillées.

Voir les détails de confidentialité sur l’App Store

Gérer vos données

Vous pouvez gérer les joueurs et les sessions dans l’application. Supprimer l’application supprime ses données locales ; les fichiers exportés et les sauvegardes se gèrent séparément. Conservez une sauvegarde avant de restaurer des données ou de supprimer l’application si vous souhaitez garder vos enregistrements.

Nous contacter

Si vous écrivez à l’assistance, votre adresse e-mail et les informations envoyées servent à répondre à votre demande. Évitez d’inclure des notes privées sur les joueurs sauf si elles sont nécessaires pour expliquer le problème.
