Assistance PokerNote

Bienvenue sur la page d’assistance de PokerNote. Vous trouverez ci-dessous les réponses aux questions fréquentes.

Questions fréquentes (FAQ)

Comment ajouter une note sur un joueur ?

Sur l’écran principal, touchez « Ajouter une note », saisissez le nom ou la description du joueur, puis vos observations dans le champ prévu. Touchez « Enregistrer » pour conserver la note.

L’application synchronise-t-elle mes notes entre mes appareils ?

Actuellement, PokerNote stocke toutes les données localement sur votre appareil. La synchronisation dans le cloud n’est pas disponible : sauvegardez régulièrement votre appareil pour protéger vos notes.
