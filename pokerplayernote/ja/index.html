01

対戦相手を覚えておく

プレイヤーの名前やメモを保存し、色やお気に入りを設定できます。思い出したいときはプレイヤーリストで検索できます。

02

読みをレンジにまとめる

視覚的なマトリックスでプレイヤーのハンドレンジを作成。選択した組み合わせや割合を確認でき、ポジション別のプリセットから始められます。

03

テーブルを整理する

5～10 席のキャッシュゲームやトーナメントのテーブルを作成。保存したプレイヤーを席に割り当て、テーブルのメモを残せます。

04

セッションを振り返る

バイイン、追加購入、キャッシュアウト、時間、場所を記録。月別、年別、全期間の利益、合計時間、平均時給を確認できます。

05

記録を持ち出す

記録を JSON バックアップとして保存したり、Numbers・Excel 向けの CSV ファイルに書き出したりできます。データの復元には JSON バックアップを使います。

06

まずは一人のプレイヤーから

「プレイヤー」を開いて + をタップし、名前とメモを入力して「プレイヤーを追加」をタップします。必要に応じて色、お気に入り、ハンドレンジを追加できます。

プレイヤーのメモを追加するには？

「プレイヤー」を開いて + をタップします。名前とメモを入力し、「プレイヤーを追加」をタップしてください。色の選択、お気に入りへの登録、ハンドレンジの設定もできます。

セッションを記録するには？

「セッション」を開いて + をタップします。バイイン、追加購入、キャッシュアウト、時間、場所などを入力してください。「すべて」「月」「年」のフィルターで記録と集計を確認できます。

データをバックアップ・書き出しするには？

「機能 → バックアップと復元」を開きます。「バックアップを書き出す」で JSON を「ファイル」に保存できます。「CSV を書き出す」ではプレイヤー、セッション、場所、テーブル、席を選んで表計算用に書き出せます。

バックアップを復元するとどうなりますか？

「機能 → バックアップと復元」で「バックアップを復元」を選び、JSON バックアップを指定します。内容を確認してから確定してください。復元は現在のすべてのデータを置き換え、取り消せません。現在の記録を残したい場合は、先にバックアップを書き出してください。CSV ファイルでは復元できません。

メモは端末間で同期されますか？

記録は端末内に保存され、自動クラウド同期はありません。別のコピーを残したり、他の端末で復元したりするには JSON バックアップを書き出してください。復元すると、復元先の端末の現在のデータが置き換わります。

アプリの対応言語は？

アプリは英語、スペイン語、繁体字中国語、簡体字中国語に対応しています。フランス語と日本語はウェブサイトの翻訳です。
