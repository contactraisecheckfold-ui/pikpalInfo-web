不只是隨手筆記

您的牌桌。
您的筆記。您的紀錄。

01

記住您的對手

儲存玩家姓名與筆記、指定顏色、標記最愛，並在需要回顧時搜尋玩家列表。

02

將判讀化為範圍

透過視覺化矩陣建立玩家手牌範圍。查看所選組合與百分比，也可使用位置預設範圍快速開始。

03

有序管理牌桌

建立 5 至 10 個座位的現金桌或錦標賽牌桌。將已儲存的玩家安排至座位，並記錄牌桌筆記。

04

回顧每次牌局

記錄買入、加碼買入、兌現金額、時間與地點。依月份、年份或所有牌局查看盈虧、總時間與平均每小時收益。

05

帶走您的紀錄

匯出紀錄的 JSON 備份，或匯出供 Numbers 與 Excel 使用的 CSV 檔案。還原資料時請使用 JSON 備份。

06

從一位玩家開始

開啟「玩家」，點選 +，輸入姓名與筆記，再點選「新增玩家」。需要更多細節時，可加入顏色、最愛標記或手牌範圍。

牌局紀錄

每次牌局，都值得記錄。

清楚記錄在哪裡玩、玩了多久，以及牌局結果。pokerNote 整合牌局詳細資訊與成果，讓您隨時回顧歷次紀錄。

  1. 記下基本資訊

    開啟「牌局」並點選 +。加入日期、開始與結束時間、地點、遊戲類型及注額，完整記錄每次牌局的背景。

  2. 掌握買入與兌現

    輸入買入、追加買入與兌現金額。牌局結果為兌現金額減去買入及追加買入。需要修正細節時，可編輯牌局紀錄。

  3. 回顧整體表現

    切換「全部」、「月」與「年」，查看所選期間的總盈虧、總遊玩時間及平均每小時收益。也可將牌局匯出為 CSV，在試算表中進一步查看。

如何新增玩家筆記？

開啟「玩家」並點選 +。輸入玩家姓名與筆記，再點選「新增玩家」。您也可以選擇顏色、將玩家標記為最愛，或設定手牌範圍。

如何記錄牌局？

開啟「牌局」並點選 +。輸入買入、加碼買入、兌現金額、時間與地點等詳細資訊。使用「全部」、「月」或「年」篩選，查看紀錄與摘要。

如何備份或匯出資料？

開啟「功能 → 備份與還原」。選擇「匯出備份」，將 JSON 檔案儲存至「檔案」；或選擇「匯出 CSV」，匯出玩家、牌局、地點、牌桌或座位，以供試算表使用。

還原備份會發生什麼事？

在「功能 → 備份與還原」中選擇「還原備份」，再選取 JSON 備份。確認前請先檢閱內容。還原會取代所有目前資料，且無法復原。若要保留目前紀錄，請先匯出備份。CSV 檔案無法用於還原資料。

應用程式會在不同裝置間同步筆記嗎？

紀錄儲存在您的裝置上，不會自動雲端同步。匯出 JSON 備份，可保留獨立副本或在其他裝置還原。還原會取代目的地裝置目前的資料。

應用程式支援哪些語言？

應用程式支援英文、西班牙文、繁體中文與簡體中文。法文與日文是網站翻譯。
